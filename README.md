## Features
- 30-minute time blocks(customizable)
- Drag-to-paint activity tracking
- Weekly report with charts
- Daily & weekly reminders
- Offline-first(AsyncStorage)
- Simple weekly goals

## Tech Stack
- React Native(Expo)
- TypeScript
- expo-router
- AsyncStorage
- victory-nativeW
